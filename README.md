# Control Flow, Sub Programs, and Unit Testing in Python

This project demonstrates the use of control flow structures, sub-programs (functions), and unit testing in Python. It provides insights into how to structure code using conditionals, loops, and how to organize code into reusable functions. Additionally, the project shows how unit testing ensures that the program works as expected.

## Introduction

This repository includes a Jupyter Notebook that covers Python concepts such as:
- Control flow (if-else, loops)
- Sub-programs (functions)
- Unit testing using `unittest` framework

The project aims to demonstrate practical examples of how these concepts are applied in Python programming.

## Technologies

This project uses the following technologies:
- **Python** (3.x)
- **Jupyter Notebook** for interactive coding
- **unittest** for unit testing

## Setup Instructions

1. Clone this repository to your local machine:

    ```bash
    git clone https://github.com/username/Control_Flow_Sub_Programs_Unit_Testing.git
    ```

2. Navigate to the project folder:

    ```bash
    cd Control_Flow_Sub_Programs_Unit_Testing
    ```

3. Install the required dependencies using `pip`:

    ```bash
    pip install -r requirements.txt
    ```

4. Open the Jupyter Notebook file:

    ```bash
    jupyter notebook Control_Flow,_Sub_Programs,_dan_Unit_Testing.ipynb
    ```
